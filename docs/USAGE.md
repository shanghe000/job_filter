# 使用指南

## 输入与输出

先复制原始职位表，再使用本工具。程序必须写入与输入不同的文件；保存过程先写临时文件，成功后再替换目标。
图形界面通过系统另存为对话框确认覆盖已有输出；命令行默认拒绝覆盖，除非加 `--overwrite`。

请选择普通 Excel 职位表。表头需要在前 15 行内，同一行包含“专业”和“学历”。第一张符合条件的表头会用于该工作表。
未识别为职位表的工作表保留并输出提示；所有页都未识别时视为错误，不输出一个看似成功的文件。

## 条件怎样匹配

- 学历：按文本中识别到的最低学历等级初筛，复杂限制需人工核对。
- 专业：逗号或中文逗号分隔关键词；若专业栏按学历分段，仅在对应段落匹配。未找到本人学历段落时不跨段匹配。
- 应届：根据招考对象、备注中的常见表述判断；不理解所有自然语言例外。
- 基层年限：支持专用年限栏的整数以及常见中文年数。
- 政治面貌：识别常见的党员要求，复杂组合条件仍需人工核对。

对年龄、户籍、资格证、学位与学历区别、专业目录编号、服务基层专项、定向岗位及其他特殊限制，没有完整判断能力。
筛选结果中“保留”只表示通过这些启发式条件，不表示符合全部报考条件。

## 格式与兼容性

保留单元格样式、列宽、对应行高、工作表顺序和标题区域合并单元格。删除行后重新设置普通筛选范围，清除旧的列筛选条件。

openpyxl 不会在删除行时自动维护公式、表格与图表引用。因此本工具会提前拒绝含这些结构的文件，也拒绝数据区域的合并单元格及命名范围。
依据见 [openpyxl 官方说明](https://openpyxl.readthedocs.io/en/stable/editing_worksheets.html)。

`.xlsm` 必须另存为 `.xlsm`，使用保留 VBA 的方式加载，但不执行或验证宏；含 ActiveX、嵌入对象等复杂扩展的工作簿不在支持范围内。
对复杂文件请在副本中粘贴为值，移除高级对象，展开数据区合并，并人工复核转换结果。

## 常见问题

**窗口空白**：macOS 系统自带旧 Tk 可能不兼容。使用带 Tcl/Tk 8.6+ 的 Python，或使用命令行入口。

**结果为零**：检查学历段落、关键词和默认非应届条件；零结果可以是有效结果，原件仍保留。

**文件正被占用**：关闭 Excel 中的目标输出文件，换一个输出名重试。

**大文件处理**：图形界面在后台处理，日志与进度提示保持可见。处理完成前请勿关闭窗口；工具不承诺任意体量的性能。
